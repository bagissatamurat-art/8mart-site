# Handoff: сайт 8mart (8mart.kz)

Маркетплейс с доставкой по Астане и другим городам Казахстана. Категории: Стройматериалы, Инструменты, Для дома, Подарки, Цветы. Продуктов и готовой еды нет.

## О файлах в пакете
Файлы в `site/` — **HTML-референсы дизайна**: прототипы, которые показывают внешний вид и поведение. Это **не production-код**. Задача — воссоздать эти экраны в стеке проекта по его паттернам. Если стека нет, рекомендуется **Next.js (App Router) + TypeScript**: стили — CSS-переменные из `tokens.css` (CSS Modules или Tailwind с этими токенами), состояние — Zustand (корзина, способ получения, избранное), данные — TanStack Query, карта — Mapbox GL JS.

Данные в `site/data.js` — мок. **Формы объектов в нём — контракт API**: замените их на запросы к API, сохранив форму объектов.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы, тексты и состояния финальные. Верстать пиксель-в-пиксель по артбордам 1440 и 390.

## Как открыть референсы
```
cd site && npx serve .     # или python3 -m http.server
```
Откройте `01 Главная и каталог.dc.html` и остальные. Нужен локальный сервер: файлы подгружают друг друга. Двойной клик не сработает. Для карты и подсказок адреса скопируйте `site/env.example.js` → `site/env.js` и вставьте ключи. `env.js` в `.gitignore`. Справа в каждом файле — панель Tweaks: в ней переключаются состояния (пусто / ошибка / загрузка / распродано и т.д.).

## Ключевые сценарии
1. Главная → выбрать способ получения (модалка, если не выбран) → карточка → в корзину → корзина → оформление → оплата (Kaspi / карта) → статус.
2. Каталог / поиск → фильтры → быстрый просмотр → вариант (размер, цвет) → в корзину.
3. Вход по коду в WhatsApp (или через Telegram-бот) → кабинет → «Повторить» заказ.

## Интеракции и поведение (сводка, детали — DESIGN_RULES.md)
- **Способ получения** выбирается до первого добавления в корзину. Модалку можно закрыть всегда. Если способ не выбран, в шапке висит «Как получить заказ?», а «В корзину» снова открывает модалку. Корзина и способ сохраняются между страницами.
- **Корзина**: распроданный товар остаётся в списке и помечен, но не входит в сумму и количество. Сверху алерт, CTA заблокирован до удаления такого товара. Заголовок склоняется: «N товар / товара / товаров» (`plural()`, `itemsTitle()`).
- **Несколько отправлений**: товар с `delivery === 'cargo'` везёт Газель на следующий день (тариф по весу), остальное везёт курьер сегодня. Если в корзине оба типа, клиент выбирает (`MartSplitChoice`). У каждого отправления своя строка стоимости. Бесплатная доставка от порога действует только для курьера.
- **CTA** всегда в формате «текст · сумма». Он disabled с объяснением причины, пока не принята оферта, не удалены распроданные товары или не выбран способ получения (`CTA_BLOCKED`). Чекбокс оферты стоит в потоке формы, а не в закреплённой панели.
- **Оплата**: только Kaspi и карта, наличных нет. Kaspi — официальный SVG кнопки без суммы. У вошедшего пользователя есть сохранённые карты (`CARDS`) и вариант «Новой картой».
- **Бонусы**: 1 бонус = 1 тг, не сгорают. Начисляются по каждому товару (`product.bonus`) после получения заказа. Списать можно до `BONUS.maxPart`% суммы.
- **Статус заказа**: доставка — Принят → Собираем → Курьер в пути → Доставлен; самовывоз — … → Готов к выдаче → Выдан; у Газели своя шкала. Отменить заказ можно, пока ни одно отправление не передано в доставку.
- **Избранное** — общий стор (`getFavorites / setFavorite / onFavorites`), синхронный на всех экранах.
- **Сторис** — см. COMPONENTS.md → MartStories.
- **Деньги**: `4 090 тг.` (пробел-разделитель, «тг.» с точкой) в ценах, в свободном тексте «тг» без точки. Функция — `money()`.
- **Motion**: hover/focus — 150 ms ease. Скелетоны пульсируют (opacity .5↔1, 1.4 с).
- **Focus** — всегда кастомное кольцо `0 0 0 3px rgba(238,29,116,.18)`.

| Стор | Поля | Персистентность |

## API-контракт (что нужно фронту)
| Метод | Ответ |
|---|---|
| `GET /categories` | `[{slug, name, img, sub:[{slug, name}]}]` |
| `GET /products?category&sub&q&sort&page&min&max&sale&inStock&<attr>` | `{items:[Product], total}` |
| `GET /products/{id}` | Product + `description, specs[[k,v]], images[], conditions?` |
| `GET /search/suggest?q` | `{categories:[…], products:[…], total}` |
| `GET /stories` | `[{id, title, cover, slides:[{img, title, text, cta?:{label, href?\|copy?}}]}]` |
| `GET /banners` | `[{img, title, text, cta, href}]` |
| `POST /cart/validate` | `{lines:[{id, qty, soldOut, price}], plan:{shipments:[…]}}` — сервер пересчитывает цены, наличие и отправления |
| `GET /cities`, `GET /pickup-points?city` | `CITIES`, `PICKUP_POINTS` (+`acceptsCargo`) |
| `GET /geo/suggest?q&city`, `GET /geo/reverse?lat&lng` | прокси DaData; secret-ключ только на бэкенде |
| `POST /promo/check {code, goodsTotal}` | `{ok, pct}` или `{error:'notFound'\|'expired'\|'minSum', minSum?}` |
| `POST /auth/code {phone, channel:'whatsapp'}` · `POST /auth/verify {phone, code}` | `{accessToken, user:{name?}}`, refresh — cookie |
| `POST /auth/tg` → `{token}` · `GET /auth/tg/{token}` | `{status:'pending'\|'ok', phone?}` |
| `POST /orders` | `{id, payUrl?}` — редирект на Kaspi / страницу шлюза |
| `GET /orders`, `GET /orders/{id}` | `ORDERS`: `{id, date, method, status, shipments:[{kind, status, eta}], items, total, bonus}` |
| `POST /orders/{id}/cancel` | `{refund:{amount, to}, bonusReturned}` |
| `GET/POST/PUT/DELETE /me/addresses` | `ADDRESSES` |
| `GET /me/cards`, `DELETE /me/cards/{id}` | `CARDS` — только маска, карты сохраняет шлюз |
| `GET /me/promos`, `GET /me/bonus` | `USER_PROMOS`, `BONUS` |
| `PATCH /me {name}` · `POST /me/phone` → `/me/phone/verify` · `DELETE /me` | личные данные |

**Product**: `{id, name, weight, pack, price, oldPrice?, badge?, cat, img, images?, bonus?, delivery?: 'express'|'cargo'|'flowers', weightKg, group?, variants?:[{id, size, price}], colors?: string[]}`. Типы статусов — `ORDER_STATUS`.

## Известные несоответствия и открытые вопросы
- Все цены, тарифы Газели, бонусы, сторис и промокоды — мок. Значения нужно уточнить у бизнеса.
- Порог бесплатной доставки в моке — 20 000 тг (`DELIVERY.freeFrom`), нужно подтвердить.
- Номер поддержки WhatsApp (`SUPPORT_WA`) и Telegram-бот (`TG_BOT`) — заглушки.
- `geo.js` в прототипе зовёт DaData из браузера. В проде — только через бэкенд.
- Юридические тексты (оферта, политика) пишет бизнес. Пока это ссылки-заглушки.
- Казахская локализация сайта не делалась.

## Промпт для Claude Code
> Прочитай `design_handoff_8mart_site/README.md`, `CLAUDE.md`, `DESIGN_RULES.md` и `COMPONENTS.md`. Подними проект на Next.js (App Router) + TypeScript. Подключи `tokens.css` и `fonts.css` глобально. Сначала собери компоненты из COMPONENTS.md со всеми состояниями и витрину `/kit`, сверься с `site/UI Kit.dc.html`. Затем сделай экраны в порядке: главная → способ получения → карточка/быстрый просмотр → корзина → оформление → статус → каталог → поиск → вход → кабинет. Desktop и mobile — по артбордам 1440/390, брейкпоинт 1024. Данные возьми из `site/data.js` (перенеси в `lib/mock.ts` с типами), за слоем `lib/api.ts`, чтобы потом заменить мок на API без изменения форм объектов. Бизнес-логику (`planShipments`, `splitOptions`, `formatPhone`, `money`, `plural`, `bonusFor`) перенеси 1:1 и покрой тестами. Секреты — только в `.env.local`.
