# Компоненты 8mart (сайт)

Исходники — `site/Mart*.dc.html` (открываются в браузере, у каждого есть Tweaks-пропсы для состояний). Значения — из `tokens.css`. Правило: элемент, повторяющийся ≥3 раз или имеющий состояния, — отдельный компонент; «почти таких же» вариантов не делать.

Все крестики, стрелки, шевроны, чекбоксы — геометрия (CSS/SVG), не символы шрифта.

---

## MartButton
Props: `label`, `amount?`, `variant: primary|secondary|ghost|danger|kaspi`, `size: 36|40|44|56`, `full`, `disabled`, `loading`, `reason?`, `onClick`.

| size | padding-x | font |
|---|---|---|
| 56 | 28 | 16/600 |
| 44 | 20 | 15/600 |
| 40, 36 | 16 | 14/600 |

Радиус pill. Бордер 1.5px.

| variant | bg | hover | active | text |
|---|---|---|---|---|
| primary | #EE1D74 | #D6136A | #BF0F5E | #FFF |
| secondary | #FDF0F6 | #FBDCEA | #F7B4D1 | #EE1D74 |
| ghost | transparent, border #E3E2E7 | #F7F7F8 | #EEEDF1 | #17151A |
| danger | #FDEDED | #FADADA | #F5C2C2 | #E23D3D |
| kaspi | официальный SVG `assets/kaspi-pay.svg` как есть, радиус pill, **без суммы** |

- **Split-CTA**: `label · разделитель · amount` — основной CTA всегда такой (кроме Kaspi).
- **disabled**: bg #EEEDF1, text #9E9BA6. Причина (`reason`) выводится текстом рядом/под CTA и в `title`.
- **loading**: спиннер поверх, текст скрыт, клики заблокированы.
- **focus**: кольцо `--focus-ring`, не браузерное.

## MartInput
Props: `label`, `value`, `type: text|phone|code|textarea`, `required`, `hint?`, `error?`, `disabled`, `focused`, `onChange`.
- Высота 56 (textarea 84), r16, border 1.5px: default #E3E2E7 → focus #EE1D74 + кольцо → error #E23D3D + красное кольцо → disabled #EEEDF1, фон #F7F7F8.
- Плавающий лейбл: пусто — 16px по центру (#6B6873); фокус/заполнено — 12px, top 9 (focus #EE1D74, error #E23D3D).
- Обязательное — красная `*` в лейбле. Слово «необязательно» не пишем.
- Кнопка очистки × (32×32, круг) — только когда поле в фокусе **и** заполнено. У телефона очистки нет.
- Текст ошибки/подсказки под полем, 13px, gap 6.
- **Телефон**: маска `+7 (999) 999-99-99`; ведущая `8` → `+7`; если после `+` не `7` — свободный международный формат. Маска работает по цифрам: Backspace по символу маски стирает соседнюю цифру; пустое поле = `''`. Реализация — `formatPhone()` / `phoneComplete()` в `data.js`.

## MartPromo
Состояния: `idle` (поле + «Применить»), `loading`, `applied` (плашка с кодом, суммой скидки и ×), ошибки `notFound` / `expired` / `minSum` (текст с суммой: «…от 15 000 тг»). Тексты ошибок — `PROMO_ERRORS` в data.js.

## MartChip
Props: `label`, `selected`, `disabled`, `removable`, `count?`, `size` (36). Pill, padding 0 14, 14/500, border 1.5.
default #FFF / border #E3E2E7 → hover #F7F7F8 → selected #FDF0F6, рамка #EE1D74, текст #BF0F5E 600 (было #17151A — решение владельца: выбранное розовым, не чёрным) → disabled #F7F7F8, текст #9E9BA6. `removable` — крестик справа (фильтры).

## MartStepper
Props: `qty`, `max`, `size` (44 / 36), `tone: primary|neutral`, `full`, `disabled`, `onChange`. Pill. primary — #EE1D74/#FFF, neutral — #F7F7F8/#17151A. «+» блокируется на `max` (opacity .4). qty → 0 удаляет позицию.

## MartProductCard
Props: `product`, `qty`, `soldOut`, `favorite`, `onFavorite`, `onOpen`, `onQty`.
- Белая карточка, r20, padding 8, gap 10. Фото 1:1, r14, фон #F7F7F8 (товары на белом).
- Сердце — правый верхний угол фото: контур #6B6873 → заливка #EE1D74. Общий стор избранного.
- Бейдж (`Товар дня` и т.п.) и скидка `−N%` поверх фото.
- Цена 16/700, старая — зачёркнутая 13 #9E9BA6. У цветов «от …».
- Бонусы: зелёная монетка «Б» (#1DA765, текст #13824D на #EAF7F0) «+N».
- Название — ровно 2 строки; низ (цена/CTA) прижат; в сетке `align-items: stretch` → одинаковая высота.
- qty=0 → кнопка «В корзину» (36, pill, #F7F7F8, текст #17151A 14/600; у цветов — «Выбрать размер»); qty>0 → MartStepper.
- soldOut: фото opacity .45, текст #9E9BA6, плашка «Раскупили», CTA нет.
- Клик по карточке → быстрый просмотр (MartProductView).

## MartProductView (быстрый просмотр / страница товара)
Desktop — модалка 1040, галерея слева sticky + миниатюры 64×64, стрелки, ←→; mobile — sheet 94% высоты, свайп-галерея с точками, CTA закреплён снизу. `page=true` — та же разметка без оверлея (08 Товар).
Состав: фото (`images`, нет — плейсхолдер), фасовки (товары одной `group`), размер (`variants`), цвет (`colors` + `COLOR_SWATCH`), бонусы, CTA, блок «Доставка / Самовывоз» по `DELIVERY_TYPES` (выбранный способ первым с меткой «Ваш способ»). Описание свёрнуто до ~5 строк с градиентом → «Читать полностью»; характеристики — 6 → «Все характеристики · N». Избранное: desktop — на фото слева сверху; mobile — рядом с названием. «Поделиться»: mobile — системный share, desktop — копирует ссылку. Esc закрывает.

## MartCartLine
Props: `product`, `qty`, `max`, `soldOut`, `compact`, `onChange`. Сетка `фото · текст · сумма/степпер`. Фото 80 (compact 64), r12; padding 12 (8); r16. Мета «фасовка · цена за шт». soldOut: фон #F7F7F8, «Нет в наличии в вашем филиале», только кнопка удалить.

## MartMiniCart (desktop, колонка 340, sticky top 16)
На главной, в каталоге, поиске, на странице товара, в кабинете. **Нет** на корзине и оформлении. Пусто — иллюстрация `empty-cart.png`. Список (max-height 288, скролл), строки доставки по `planShipments()`, прогресс до бесплатной доставки (только курьер), итог, CTA «Оформить · сумма».

## MartHeader
Props: `mode: desktop|mobile`, `method`, `address`, `userName`, `query`, `searchFocused`, `onMethod`, `onQuery`…
- Desktop 80: лого · способ получения (точка: выбран #1DA765 / не выбран #F59E0B, «Как получить заказ?») · поиск (фокус — розовый бордер + кольцо) · кнопка меню (бургер + аватар-инициал / «Войти»). **Корзины в шапке нет.**
- Меню — боковая панель справа 420, затемнение, крестик, Esc, клик по фону. Гость: плашка «Войдите» + «Войти». Пользователь: имя/телефон, активный заказ со статусом (#FDF0F6), разделы кабинета со счётчиками (строки 48), «Выйти» серым. Далее у всех — категории и поддержка (WhatsApp, телефон).
- Mobile 124: белый блок, r24 снизу; строка способа получения + поиск.

## MartTabBar (mobile)
4 вкладки: Главная · Каталог · Корзина (счётчик) · Профиль. Высота 84 (padding 8/8/20), белый, линия сверху #EEEDF1. Активная #EE1D74, неактивная #9E9BA6, подпись 11/600. Плавающей кнопки корзины над таб-баром нет.

## MartSearch
Подсказки: пусто — недавние + популярные (чипы); ввод — категории и товары (строка 60: фото 44 r10, совпадение жирным, цена справа), «Показать все N». Desktop — выпадающая панель под полем с затемнением; mobile — отдельный экран.

## MartFilters
Цена от–до + группы по категории (`CAT_FILTERS`: стройматериалы — фасовка; цветы — размер, цвет) + переключатели «В наличии», «Со скидкой». Mobile — в bottom sheet с CTA «Показать N товаров»; desktop — в сайдбаре, применяется сразу, «Сбросить».

## MartMethodModal (способ получения)
Карта Mapbox GL (`map.html` в iframe, сообщения `postMessage` `8mart-map` ↔ `8mart-parent`) + свич Доставка/Самовывоз + город (`CITIES`).
- Доставка: пин по центру, адрес по пину (обратное геокодирование), правка вручную. Подсказки адреса — с 3 символов, debounce 300 мс, до 6 вариантов в выбранном городе; строка 48 (mobile 56): улица+дом / подпись район·город; ↑↓ Enter Esc. Выбор → карта летит к точке без повторного геокодирования. Улица без дома → «Улица, » и курсор остаётся. Состояния: загрузка / ничего не нашли / сервис недоступен (→ «поставьте пин»).
- Самовывоз: точки на карте синхронны со списком (`PICKUP_POINTS`).
- Закрыть можно всегда. `address-only` — режим для кабинета.

## MartShipmentHead / MartSplitChoice (несколько отправлений)
`MartShipmentHead`: метка «Доставка 1 из 2», когда, машина · вес, стоимость; `kind: courier|cargo`. `MartSplitChoice`: «Двумя доставками» (по умолчанию) / «Всё вместе завтра»; для самовывоза — «Забрать в два приёма» / «Всё завтра со склада». Логика — `planShipments()` / `splitOptions()`.

## MartAuth
Шаги: телефон → код (4 ячейки поверх одного скрытого input, `autocomplete="one-time-code"`, проверка на 4-й цифре, успех — ячейки зелёные) → «Как вас зовут?» (новый). Код приходит в WhatsApp; ссылка «Нет WhatsApp? Войти через Telegram» → бот (desktop — QR на `t.me/<bot>?start=<token>` + «Открыть Telegram на компьютере»; mobile — только кнопка), ждём подтверждения от бэкенда. `purpose="changePhone"` — смена номера в кабинете.

## MartAccount (разделы кабинета)
Мои заказы, Избранное, Адреса, Способы оплаты, Промокоды, Бонусы, Личные данные. Загрузка — скелетоны (пульс 1.4 с). Удаление аккаунта — серой ссылкой внизу с подтверждением → главная `?deleted=1` с тостом.

## MartStories
Props: `mode: desktop|mobile`.
- Миниатюры: прямоугольные 88×116 (desktop 104×140), r18, кольцо 2.5px: непросмотренные #EE1D74, просмотренные #E3E2E7 (`localStorage '8mart.storiesSeen'`). Название белым 12/600 внизу на градиенте `transparent → rgba(23,21,26,.72)`. Gap 8 (desktop 12), горизонтальный скролл.
- Просмотр: desktop — карточка 400×711 (r20) по центру на `--overlay-strong` + круглые стрелки 44 по бокам, клик по фону закрывает; mobile — на весь экран.
- Сверху: прогресс-полосы 3px (по числу слайдов), аватар 32 + название, пауза-индикатор, крестик 40. Заголовок 30/800, текст 16 — вёрсткой поверх картинки (в картинках текста нет). CTA — MartButton 56 full, снизу 16 (mobile 34).
- Поведение: автопереход `STORY_DURATION` (6 с); тап левая треть — назад, остальное — вперёд; удержание >250 мс — пауза; свайп вниз >80 — закрыть; свайп вбок >60 — соседняя история; клавиши ← → Esc Пробел. После последней — закрыть. Следующая картинка предзагружается.
- CTA: `href` — переход; `copy` — копирует строку, текст «Код скопирован» 1.8 с, таймер на паузе.
- Сторис с товаром (`story.product`, привязка в панели): снизу вместо CTA — белая карточка MartProductStrip (`actions`, `link`), отступы как у CTA. Покупатель нажал в ней что-нибудь — история на паузе; касание картинки — продолжить.

## Видео товара (решение владельца 04.11)
Один вертикальный ролик на товар (`product.video`: `src` со звуком, `preview` — беззвучные 6 с, `poster`). Витрина — `/kit#video`.
- **VideoThumb** — миниатюра поверх галереи справа сверху: 9:16, r14, ширина 22 % (desktop, над стрелкой) / 25 % (mobile), в листе быстрого просмотра — под крестиком. Беззвучное превью по кругу (`muted playsInline loop`, `preload="metadata"`); «уменьшить движение», экономия трафика, сеть 2G/3G — только обложка. Значок ▶ слева снизу, крестик 24 справа сверху (зона 44) — скрыть до конца сессии (`sessionStorage 8mart.videoHidden`). Нажатие — плеер.
- **MartVideoPlayer** — тёмный фон (`--ink-1`; desktop — рамка 400 по центру на `--overlay-strong` и крестик 44 справа сверху). Ролик целиком (contain), со звуком по нажатию на миниатюру (не дал браузер — без звука, динамик перечёркнут). Сверху белые кнопки 44: «Назад» слева, пауза и звук справа. Тап — пауза (▶ 72 по центру), Пробел — тоже. Полоса прогресса 3px над блоком товара. Справа колонка: «В избранное», «Отзывы» (только у товара с опубликованными отзывами — лист со списком поверх видео), «Поделиться» (mobile — системное меню, иначе копирует ссылку). Снизу — лист r24 с MartProductStrip. Закрыть: «Назад», крестик, Esc, свайп вниз >80, «назад» в браузере.
- **MartProductStrip** — блок товара в плеере и сторис: фото 56 r12, название в 2 строки, цена (`money()`; варианты без выбранного размера — «от …»), чипы размеров, CTA 56 «В корзину · цена» → степпер + «В корзине · сумма» (через `setCartQty`: без способа получения — модалка). Размер не выбран — CTA заблокирован «Выберите размер». `actions` — сердце и «Поделиться» 44 в строке товара.

## Отзывы о товарах (решение владельца 04.11)
Только настоящие: оставляет покупатель, получивший товар (один отзыв на товар в заказе), на сайте — только опубликованные после проверки. Витрина — `/kit#reviews` (демо-данные с пометкой «Пример»).
- **Stars** — звёзды SVG-геометрией, закрашенные `--star` (розовый), пустые `--star-off`; дробная средняя закрашивает звезду частично. 18 — у средней в блоке, 16 — у названия, 14 — в отзыве.
- **StarsInput** — пять кнопок 44 (звезда 32 в форме, 28 в «Оцените букет»). В форме — радиогруппа: стрелки меняют оценку, под звёздами словом («Ужасно … Отлично»). `pick` — в «Оцените букет»: нажатие сразу открывает форму с этой оценкой.
- **RatingLink** — под названием товара: звёзды 16 · «4,8» · «23 отзыва», 36 (зона касания 44); нажатие — прокрутка к блоку и фокус на его заголовок.
- **MartReviews** — блок под характеристиками карточки (страница и быстрый просмотр) и в листе поверх видео: заголовок «Отзывы» 17, средняя 24/800 + звёзды 18 + число, отзывы (сначала с текстом и фото), «Показать ещё · N» (страница — 5 отзывов). Страница товара отдаёт первую страницу в серверном HTML; быстрый просмотр и плеер грузят её сами (скелетон). У товара без опубликованных отзывов блока нет.
- **ReviewCard** — подпись 15/600 («Айгерим К.» или «Покупатель», телефона нет никогда), дата 13 справа, звёзды 14 и «Размер M», текст 15/1.55 как написал покупатель (переносы сохраняются, длинный — свёрнут до 6 строк, «Читать полностью»), фото 72 r12 (нажатие — PhotoViewer), «Ответ магазина» — плашка `--surface-subtle` r12. Без текста — только оценка.
- **PhotoViewer** — фото на весь экран на `--overlay-strong`: белые кнопки 44 (крестик, стрелки), «1 / 3», ←→ и свайп, Esc.
- **ReviewForm** — desktop окно 520 r24 p28, mobile — лист снизу: товар 56 + «Оцените букет» / «Оцените товар», StarsInput, textarea «Расскажите о букете» (до 1000, «Осталось N знаков» с 900), фото до 3 (72, «убрать» 24 с зоной 44, плитка «+ Фото» пунктиром; уменьшаются на телефоне до 2048 px, без координат съёмки), подпись «Отзыв появится на сайте после проверки…», CTA 56 «Отправить отзыв» — без оценки заблокирован с причиной «Поставьте оценку».
- **ReviewPrompts** («Оцените букет») — на странице заказа карточкой под шкалой и в «Моих заказах» под полученным заказом (compact: только без отзыва). Без отзыва — фото 56 (compact 44), «Оцените букет», название, звёзды-кнопки; с отзывом — «Ваш отзыв» + статус чипом (На проверке — розовый, Опубликован — зелёный, Не опубликован — красный), причина отказа, ответ магазина.
- **В плеере видео** кнопка «Отзывы» (только у товара с опубликованными отзывами) открывает тот же список листом снизу внутри рамки плеера (`MartSheet inside`): ролик на паузе, после закрытия — продолжает. Esc закрывает лист, затем плеер.
